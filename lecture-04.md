## Що ми сьогодні розкриємо

- зрозуміти, навіщо символам потрібні числові коди
- познайомитися з ASCII, Unicode та UTF-8
- уміти отримати код символу й побачити його байти

## Букві потрібен номер

Комп’ютер не може покласти всередину пам’яті справжню літеру `A`. Він зберігає числа. Тому люди домовилися: кожному символу призначити номер.

Наприклад, у таблиці ASCII латинська велика `A` має номер 65, `B` — 66, а цифра-символ `0` — 48. Така таблиця дозволяє різним програмам однаково тлумачити ті самі числа.

## ASCII було замало для світу

ASCII створювався для невеликого набору символів і добре працював з англійською. Але у світі є українська, японська, арабська, математичні знаки, emoji та тисячі інших символів.

Тому з’явився **Unicode** — велика система кодових точок для символів багатьох мов. Наприклад, `М` має власну Unicode-кодову точку.

## UTF-8 — спосіб перетворити Unicode на байти

Unicode відповідає на питання «який номер має символ», а **UTF‑8** визначає, як цей номер записати одним або кількома байтами.

Англійські ASCII-символи в UTF‑8 займають один байт. Багато українських літер — два байти. Emoji можуть займати ще більше.

Тому важливо розрізняти:

```text
символ → Unicode-код → байти UTF-8
```

## Приклади

### Приклад 1

У Python `ord("A")` дає `65`, а `chr(65)` повертає `A`. Це два напрямки одного перекладу.

### Приклад 2

`"A".encode("utf-8")` покаже один байт, а `"М".encode("utf-8")` — кілька байтових значень.

### Приклад 3

`bin(ord("A"))` показує двійковий запис числа 65. Так ми пов’язуємо цю лекцію з двійковою системою.

## Python-лабораторія: розбираємо ім’я на коди

```python
name = "Марко"

for letter in name:
    code = ord(letter)
    print(
        letter,
        "Unicode:", code,
        "binary:", bin(code),
        "UTF-8:", letter.encode("utf-8")
    )
```

Потім спробуй змінити `name` на `Marko` і порівняй результат.

## Терміни однією фразою

- **Код символу** — номер, який домовлено дати кожному символу (наприклад `A` = 65).
- **ASCII** — старий алфавіт символів з невеликим набором (переважно англійська).
- **Unicode** — велика система номерів для символів багатьох мов, знаків та emoji.
- **Кодова точка** — номер конкретного символа в Unicode.
- **UTF-8** — правила, як записати Unicode-номер одним або кількома байтами.
- **`ord()` / `chr()`** — Python-функції: `ord` дає номер символа, `chr` повертає символ за номером.

## Що потрібно винести з лекції

- текст у комп'ютері представлений числовими кодами та байтами
- ASCII — старий невеликий набір символів, Unicode охоплює значно більше мов і знаків
- UTF‑8 — популярний спосіб кодувати Unicode-символи у байти
