# Лекція 26. Користувачі та права доступу

> **Рівень 5: Оператор операційної системи**
>
> Марко, сьогодні ми не просто вивчимо новий термін — ми відкриємо ще один шар того, як насправді працює комп’ютер.

## Що ми сьогодні розкриємо

- зрозуміти owner/group/others
- читати базовий запис `rwx`
- надати власному скрипту право на виконання

## Не всі повинні мати однакові ключі

На сімейному комп’ютері один користувач не повинен випадково змінити приватні файли іншого. На сервері це ще важливіше. Linux прив’язує файли до власників і груп та перевіряє **права доступу**.

## r, w, x

Для файлу:
- `r` — read, читати;
- `w` — write, змінювати;
- `x` — execute, запускати як програму.

`ls -l` показує щось на кшталт:

```text
-rwxr-xr--
```

Після першого символу йдуть три трійки: права **owner**, **group**, **others**.

## chmod змінює права

Команда `chmod +x script.sh` додає право на виконання. Це не «перетворює файл у програму» — вміст уже має бути придатним до виконання, але система тепер дозволяє запускати файл напряму відповідним способом.

## Приклади

### Приклад 1

`-rw-r--r--`: власник може читати й змінювати; група та інші — лише читати.

### Приклад 2

`chmod +x hello.sh` додасть `x` принаймні відповідно до режиму, який визначає команда; у простій лабораторії ми спостерігаємо зміну через `ls -l`.

### Приклад 3

`whoami` показує ім’я поточного користувача, `id` — додаткові ідентифікатори та групи.

## Linux-лабораторія: запускаємо власний скрипт

```bash
mkdir -p ~/marko-lab/permissions
cd ~/marko-lab/permissions
cat > hello.sh <<'EOF'
#!/bin/bash
echo "Привіт, Марко!"
EOF

ls -l hello.sh
chmod +x hello.sh
ls -l hello.sh
./hello.sh
whoami
id
```

Порівняй рядки `ls -l` до і після `chmod +x`.

## Місія для Марка

Виконай місію по черзі. Якщо щось не виходить — спочатку перечитай приклад вище й спробуй знайти, на якому кроці результат відрізняється.

1. виконай лабораторію
2. обведи у виводі `ls -l` трійку прав власника
3. поясни значення `r`, `w`, `x` саме для файлу
4. зміни текст скрипта і запусти знову
5. запиши результат `whoami` та назви власника файлу з `ls -l`

## Що потрібно винести з лекції

- права доступу обмежують, хто може читати, змінювати й виконувати файли
- `ls -l` показує права й власника
- `chmod` змінює дозволи, а не зміст файлу
