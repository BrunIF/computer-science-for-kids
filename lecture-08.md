## Алгоритм — план дій

Марко, ти вже писав Python, тому слово **алгоритм** тобі знайоме. Але зараз подивимося на нього ширше. Алгоритм — це точний порядок кроків, який веде від початкового стану до результату.

Рецепт млинців — алгоритм. Інструкція LEGO — алгоритм. Маршрут «вийти з дому → повернути праворуч → перейти дорогу» — теж алгоритм. Хороший алгоритм має бути достатньо точним, щоб виконавець не вгадував, що автор мав на увазі.

## Програма — алгоритм мовою, яку може виконати комп’ютер

Алгоритм можна написати українською, намалювати блок-схемою або реалізувати Python-кодом. **Програма** — це конкретний запис інструкцій для комп’ютера певною мовою програмування.

Один і той самий алгоритм сортування можна реалізувати Python, JavaScript або C. Алгоритмічна ідея лишається, а форма програми змінюється.

## Код і дані грають різні ролі

Повернімося до кухонної аналогії:

```text
рецепт       → код / програма
продукти     → дані
кухар        → CPU
робочий стіл → RAM
```

У `print(name.upper())` код каже, що робити, а `name` містить дані, над якими виконується дія. На дуже низькому рівні і код, і дані зберігаються байтами, але **їхня роль різна**.

## Python-лабораторія: один алгоритм трьома способами

Задача: визначити, парне число чи ні.

**Словами:**
1. Отримати число.
2. Знайти остачу від ділення на 2.
3. Якщо остача 0 — число парне.

**Псевдокод:**

```text
READ number
IF number MOD 2 == 0
    PRINT "парне"
ELSE
    PRINT "непарне"
```

**Python:**

```python
number = int(input("Число: "))
if number % 2 == 0:
    print("парне")
else:
    print("непарне")
```

## Терміни однією фразою

- **Алгоритм** — точний порядок кроків, що веде до результату (рецепт, інструкція LEGO).
- **Програма** — алгоритм, записаний мовою програмування, яку виконує комп’ютер.
- **Інструкція** — один конкретний крок для виконавця.
- **Псевдокод** — запис алгоритму «по-людськи», між звичайною мовою і кодом.
- **Код** — вказівки, що робити (рецепт).
- **Дані** — те, над чим виконуються дії (продукти).
- **Блок-схема** — малюнок алгоритму зі стрілками та фігурами.
