## Файл — контейнер байтів

Коли ти бачиш `photo.jpg` у файловому менеджері, інтерфейс показує красиву іконку. Але для системи файл — передусім послідовність байтів, яку можна прочитати за певними правилами.

До файлу також прив’язані метадані: ім’я, розмір, час зміни, права доступу та інша службова інформація. Тобто «файл» — це не лише його вміст.

## Ім’я допомагає людині, вміст — програмі

Ім’я `homework.txt` зручне для нас, але програма не повинна довіряти лише назві. Вміст може не відповідати розширенню. Саме тому Linux має інструмент `file`, який намагається визначити тип за вмістом та сигнатурами.

## Файл живе у файловій системі

Щоб знайти файл, система використовує шлях. Поки що достатньо пам’ятати: файл має місце у структурі папок. У лекції 19 ми побудуємо повну карту Linux-шляхів.

## Linux-лабораторія: подивимося на файли без магії

Створи навчальну папку й кілька безпечних файлів:

```bash
mkdir -p ~/marko-lab/files
cd ~/marko-lab/files
printf 'Hello, Marko!
' > hello.txt
printf 'print("hi")
' > program.py
file hello.txt
file program.py
ls -l
```

`ls -l` покаже метадані, а `file` спробує описати вміст.

## Терміни однією фразою

- **Файл** — контейнер байтів, у якого є вміст, ім’я та метадані.
- **Метадані** — дані про дані: ім’я, розмір, час зміни, права доступу.
- **Розширення** — частина імені після крапки (`.txt`, `.py`); підказка, а не гарантія формату.
- **Шлях** — маршрут до файлу в дереві папок.
- **Файлова система** — структура, яка організовує файли та каталоги.
- **`file`** — команда, що намагається визначити тип файлу за його вмістом.

## Що потрібно винести з лекції

- файл містить байти, але має також ім’я та метадані
- розширення корисне, але не є гарантією реального формату
- Linux дозволяє досліджувати файли інструментами `file` і `ls`
