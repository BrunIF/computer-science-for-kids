Цей вебсайт містить навчальний курс «Як насправді працює комп'ютер» — практичний курс фундаментальної інформатики для Марка, учня 4-го класу, який уже має базовий досвід Python.

Linux (Ubuntu/Debian) використовується як **лабораторія**, де абстрактні поняття можна побачити на реальному комп'ютері.

## Як побудований курс

Курс іде від найменшого рівня — **інформації, бітів і байтів** — до заліза, файлів, операційної системи, мереж, безпеки, Git і фінального інтеграційного проєкту. Кожна наступна лекція спирається лише на матеріал поточної або попередніх лекцій.

У кожній лекції є:

- **«Що ми сьогодні розкриємо»** — чіткі цілі;
- **«Зв'язок з попередніми лекціями»** — які знання з минулого використовуються;
- пояснення простими словами та інженерні аналогії;
- кілька конкретних прикладів;
- **Linux/Python/Git-лабораторія**;
- **«Місія для Марка»** для закріплення;
- **«Перевір себе»**;
- **«Терміни однією фразою»** — короткий словник лекції;
- **«Чек-лист перед наступною лекцією»**;
- короткий список того, що треба винести з заняття.

## Рівні курсу

1. **Рівень 1. Мисливець за даними** — інформація, біти, байти, текст, пікселі, звук.
2. **Рівень 2. Архітектор логіки** — алгоритми, булева логіка, двійкова арифметика.
3. **Рівень 3. Дослідник заліза** — CPU, RAM, HDD/SSD, периферія, драйвери.
4. **Рівень 4. Хранитель файлів** — файли, формати, каталоги, диски, архіви.
5. **Рівень 5. Оператор операційної системи** — ОС, kernel/shell, процеси, права.
6. **Рівень 6. Мережевий слідопит** — LAN, IP, роутер, ping, DNS, HTTP, протоколи.
7. **Рівень 7. Вартовий цифрової фортеці** — автентифікація, хешування, безпека.
8. **Рівень 8. Хранитель історії коду** — Git, GitHub, гілки, `.gitignore`.
9. **Рівень 9. Linux-інженер лабораторії** — діагностика, процеси, pipes, Bash-скрипти.
10. **Рівень 10. Фінальний інженерний рейд** — проєкт Computer Detective.

## Фінальна мета

Після курсу Марко має не просто знати набір Linux-команд. Він повинен уміти пояснити ланцюжок: **дані → біти/байти → представлення тексту/зображень/звуку → CPU/RAM/накопичувач → файли → ОС і процеси → мережа/IP/DNS/HTTP → безпека → Git**, а також дослідити власну систему та створити фінальний проєкт **Computer Detective**.
