# Курс «Як насправді працює комп’ютер» для дітей

Практичний курс фундаментальної інформатики для Марка, учня 4-го класу, який уже має базовий досвід Python. Linux (Ubuntu/Debian) використовується як **лабораторія**, де абстрактні поняття можна побачити на реальному комп’ютері.

## Як побудований курс

Курс іде від найменшого рівня — **інформації, бітів і байтів** — до заліза, файлів, операційної системи, мереж, безпеки, Git і фінального інтеграційного проєкту. Кожна наступна лекція спирається лише на матеріал поточної або попередніх лекцій.

У кожній лекції є:

- **«Що ми сьогодні розкриємо»** — чіткі цілі;
- **«Зв'язок з попередніми лекціями»** — які знання з минулого використовуються;
- пояснення простими словами та інженерні аналогії;
- кілька конкретних прикладів;
- **Linux/Python/Git-лабораторія**;
- **«Місія для Марка»** для закріплення;
- **«Перевір себе»**;
- **«Терміни однією фразою»** — короткий словник лекції;
- **«Чек-лист перед наступною лекцією»** — перевірка готовності до наступної теми;
- короткий список того, що треба винести з заняття.

Для зручності пошуку створено окремий файл [**Словник курсу**](glossary.md) з усіма термінами в алфавітному порядку.

## Правила лабораторії

1. Команди спочатку **читаємо й пояснюємо**, а потім запускаємо.
2. Вправи з видаленням виконуються лише в навчальних каталогах `~/marko-lab/...`.
3. `sudo` використовується лише там, де в лекції пояснено навіщо, і разом із дорослим.
4. Не підключаємо невідомі USB-пристрої.
5. Не вводимо й не коммітимо реальні паролі, 2FA-коди, токени, приватні ключі чи інші секрети.
6. Перед публікацією на GitHub перевіряємо, чи немає приватних даних.

## Рекомендований ритм

Для 9-річної дитини краще не гнатися за номером лекції. Одне заняття можна розділяти на дві зустрічі: спочатку пояснення й приклади, потім лабораторія та місія. Перехід далі має сенс, коли Марко:

- може **своїми словами пояснити головну ідею**, а не лише повторити команду;
- відмітив усі пункти **«Чек-листа перед наступною лекцією»**.

Швидко повторити терміни можна в [**Словнику курсу**](glossary.md).

## Фінальна мета

Після курсу Марко має не просто знати набір Linux-команд. Він повинен уміти пояснити ланцюжок: **дані → біти/байти → представлення тексту/зображень/звуку → CPU/RAM/накопичувач → файли → ОС і процеси → мережа/IP/DNS/HTTP → безпека → Git**, а також дослідити власну систему та створити фінальний проєкт **Computer Detective**.

## Веб-сайт курсу

Лекції та словник також публікуються у вигляді зручного навігаційного сайту на базі [Astro Starlight](https://starlight.astro.build): `https://brunif.github.io/computer-science-for-kids/`.

Єдине джерело правди — файли `lecture-*.md` і `glossary.md` у корені репозиторію. Перед кожною збіркою скрипт `docs-site/scripts/sync-content.mjs` копіює їх у `docs-site/src/content/docs/`, додаючи необхідний YAML-заголовок (`title`) без зміни оригіналів.

### Локальний запуск

```bash
cd docs-site
npm install        # або npm ci
npm run dev        # режим розробки
npm run build      # продуктивна збірка у docs-site/dist/
```

### Деплой — GitHub Actions

Сайт будується та розгортається автоматично через GitHub Actions (`.github/workflows/deploy.yml`) після кожного push у гілку `main`. Один раз уручну налаштуйте GitHub Pages:

1. Відкрийте **Settings → Pages** репозиторію.
2. У полі **Source** оберіть **GitHub Actions**.
3. Після наступного push сайт буде опублікований за вказаною вище адресою.

> Примітка: `package-lock.json` у `docs-site/` має бути закомічений — workflow використовує `npm ci` для відтворюваної збірки.
