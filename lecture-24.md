## Kernel — центральний керівник низького рівня

**Ядро (kernel)** керує процесами, пам’яттю, пристроями та іншими фундаментальними ресурсами. Linux у строгому технічному сенсі — це саме ядро, хоча в побуті «Linux» часто називають цілу операційну систему на його основі.

## Shell — командний перекладач

Коли ти вводиш `ls`, shell читає текст, розбирає аргументи й запускає потрібну програму або виконує власну команду. Bash — один із популярних shell. Є також zsh, fish та інші.

## Terminal — вікно/середовище для текстової розмови

Термінальний емулятор показує символи, приймає натискання клавіш і дає тобі сеанс shell. Спрощена схема:

```text
ти → terminal → shell → програми / системні виклики → kernel → hardware
```

Не кожна команда йде до ядра одним прямим кроком, але модель допомагає розкласти ролі.

## Приклади

### Приклад 1

GNOME Terminal може запускати Bash. Якщо закрити вікно terminal, це не означає «видалити Bash із системи».

### Приклад 2

`echo $SHELL` зазвичай показує шлях до shell, налаштованого для користувача.

### Приклад 3

`uname -r` показує версію ядра, а `bash --version` — версію Bash. Це різні компоненти.

## Linux-лабораторія: хто є хто?

```bash
echo $SHELL
bash --version | head -n 1
uname -r
ps -p $$ -o comm=
```

Остання команда намагається показати назву shell поточного процесу. Результат може залежати від середовища.

## Місія для Марка

Виконай місію по черзі. Якщо щось не виходить — спочатку перечитай приклад вище й спробуй знайти, на якому кроці результат відрізняється.

1. запиши шлях із `echo $SHELL`
2. запиши версію ядра і версію Bash окремо
3. намалюй схему terminal → shell → kernel → hardware
4. поясни, чому `terminal` і `shell` не є синонімами
5. назви приклад дії, де shell запускає окрему програму, наприклад `ls`

## Терміни однією фразою

- **Kernel (ядро)** — центральний керівник низького рівня: процеси, пам’ять, пристрої.
- **Shell (оболонка)** — командний перекладач: читає текст команди й запускає програми.
- **Terminal emulator (термінал)** — вікно, яке показує символи та дає сеанс shell.
- **Bash** — один популярний shell (є ще zsh, fish).
- **Системний виклик** — «прохання» програми до ядра щось зробити.
- **`echo $SHELL`** — команда, що показує шлях до shell користувача.
