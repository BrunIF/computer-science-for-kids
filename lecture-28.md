# Лекція 28. Пакетні менеджери та репозиторії

> **Рівень 5: Оператор операційної системи**
>
> Марко, сьогодні ми не просто вивчимо новий термін — ми відкриємо ще один шар того, як насправді працює комп’ютер.

## Що ми сьогодні розкриємо

- зрозуміти, що таке пакет, залежність і репозиторій
- побачити, чим `apt` відрізняється від завантаження випадкових інсталяторів
- встановити маленький навчальний пакет

## Правило лабораторії

Встановлення системних пакетів змінює комп’ютер. Усі `sudo apt ...` у курсі виконуємо разом із дорослим і лише для зрозумілих пакетів.

## Пакет — підготовлений набір для системи

Програма часто складається не з одного файлу. Потрібні виконувані файли, бібліотеки, документація, метадані. Дистрибутиви Linux пакують це у **packages**.

## Залежності — деталі LEGO, які потрібні іншим деталям

Одна програма може використовувати бібліотеку, яка вже створена іншими розробниками. Це **dependency**. Пакетний менеджер допомагає встановити потрібні залежності та стежити за версіями.

## Репозиторій — перевірене джерело пакетів для дистрибутива

`apt` отримує списки пакетів із налаштованих репозиторіїв. `apt update` оновлює інформацію про доступні версії; це не те саме, що автоматично оновити всі програми.

Перевага пакетного менеджера — централізовані джерела й керування. Це не означає, що будь-який пакет абсолютно безризиковий, але модель значно краща за випадкове завантаження невідомих скриптів.

## Приклади

### Приклад 1

`sudo apt update` оновлює локальний список інформації про пакети.

### Приклад 2

`sudo apt install cowsay` просить пакетний менеджер встановити `cowsay` та потрібні залежності.

### Приклад 3

Після встановлення команда `apt show cowsay` може показати опис пакета.

## Linux-лабораторія: встановлюємо корову

Разом із дорослим на Ubuntu/Debian:

```bash
sudo apt update
sudo apt install cowsay
```

Потім спробуй:

```bash
cowsay "Привіт, Марко!"
```

На деяких системах виконуваний файл може опинитися поза поточним `PATH`; тоді це окремий привід дослідити, де пакет його встановив.

## Місія для Марка

Виконай місію по черзі. Якщо щось не виходить — спочатку перечитай приклад вище й спробуй знайти, на якому кроці результат відрізняється.

1. перед встановленням поясни, що зробить кожна з двох apt-команд
2. встанови `cowsay` разом із дорослим
3. запусти `cowsay` із трьома різними повідомленнями
4. виконай `apt show cowsay` і знайди короткий опис
5. поясни різницю між пакетом, залежністю і репозиторієм
