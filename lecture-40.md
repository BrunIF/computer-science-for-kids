## Шифрування має шлях назад із ключем

При **шифруванні** дані перетворюються на шифротекст, а той, хто має правильний ключ і алгоритм, може їх розшифрувати. Це потрібно, коли інформацію треба зберегти секретною, але пізніше прочитати.

## Хеш — односторонній цифровий відбиток

Хеш-функція бере дані будь-якого розміру й створює значення фіксованої довжини. Для криптографічних хешів ми очікуємо, що практично неможливо відновити початкові дані лише з хешу та дуже складно підібрати інші дані з тим самим відбитком.

Хешування не є «шифруванням без ключа». Мета інша.

## Маленька зміна — зовсім інший відбиток

Якщо змінити один символ у файлі, SHA-256 зазвичай зміниться кардинально. Саме тому хеші корисні для перевірки цілісності: «чи байти залишилися тими самими?»

### Приклад 2

### Приклад 3

Зберігання паролів у реальних системах вимагає спеціальних password-hashing алгоритмів із salt і параметрами вартості; простий SHA-256 сам по собі для бази паролів не підходить. Ми не будуємо систему логіну в цій лекції.

## Python-лабораторія: цифровий відбиток

```python
import hashlib

text = "training-message"
data = text.encode("utf-8")
digest = hashlib.sha256(data).hexdigest()

print("Текст:", text)
print("SHA-256:", digest)
```

Потім зміни лише одну літеру й порівняй хеші.

Для навчального файлу Linux також часто має:

```bash
sha256sum ~/marko-lab/files/hello.txt
```

## Терміни однією фразою

- **Шифрування (encryption)** — перетворення даних на незрозумілі без ключа.
- **Ключ** — секретне значення для шифрування/розшифрування.
- **Хеш (hash)** — односторонній відбиток фіксованої довжини.
- **SHA-256** — популярний криптографічний алгоритм хешування.
- **Цілісність (integrity)** — стан, коли байти даних залишилися незмінними.
- **Соль (salt)** — додаткове випадкове значення для ускладнення підбору паролів.
- **`sha256sum`** — Linux-команда, що рахує SHA-256 для файлу.

## Що потрібно винести з лекції

- шифрування захищає секретність і має контрольований шлях розшифрування
- хешування створює односторонній відбиток
- хеш корисний для перевірки цілісності даних
