## Кодування: домовитися, як представити дані

**Кодування** потрібне, щоб представити інформацію за певними правилами. UTF‑8 кодує символи байтами. Base64 може представити байти набором текстових символів.

Кодування не обов’язково робить дані секретними. Якщо правила відомі, їх зазвичай легко перетворити назад.

## Стиснення: прибрати зайве повторення

**Стиснення** намагається представити ті самі дані компактніше. Уяви рядок:

```text
AAAAAAAAAABBBBB
```

Замість буквального повторення можна було б умовно записати `10×A, 5×B`. Реальні алгоритми значно розумніші, але ідея схожа: використати закономірності й повтори.

Стиснення буває без втрат і з втратами. ZIP має відновити дані точно. JPEG може відкинути частину деталей, які менш помітні оку.

## Шифрування: зробити дані незрозумілими без секрету

**Шифрування** має іншу мету — конфіденційність. Повідомлення перетворюють так, щоб без ключа його було складно прочитати.

Шифр Цезаря, який ми використаємо, сьогодні не є безпечним. Це лише навчальна модель: він показує ідею перетворення символів за правилом. Реальні системи шифрування незрівнянно складніші.

## Приклади

### Приклад 1

UTF‑8: `Марко` → байти. Мета — однаково зберегти текст.

### Приклад 2

ZIP: папка з багатьма текстовими файлами → компактніший архів. Мета — менше місця.

### Приклад 3

Шифрування: повідомлення + секретний ключ → шифротекст. Мета — приховати зміст від стороннього читача.

## Python-лабораторія: навчальний Caesar +1

Почнемо лише з латинських малих букв, щоб правило було прозорим:

```python
letter = input("Введи маленьку латинську літеру a-z: ")

if letter == "z":
    encrypted = "a"
else:
    encrypted = chr(ord(letter) + 1)

print("Зашифровано:", encrypted)
```

Тут ми використовуємо знання з лекції про коди символів. Для `a` беремо номер через `ord()`, додаємо 1 і повертаємо символ через `chr()`.

## Терміни однією фразою

- **Encoding (кодування)** — домовитись, як записати інформацію за правилами (наче домовитися, якими символами писати листа). Не робить дані секретними.
- **Compression (стиснення)** — упакувати ті самі дані, щоб вони займали менше місця (наче скласти ковдру, щоб увійшла в шафу).
- **Encryption (шифрування)** — перемішати дані так, щоб без секретного ключа їх було складно прочитати.
- **Lossless (без втрат)** — стиснення, при якому все відновлюється точно (ZIP).
- **Lossy (з втратами)** — стиснення, що відкидає частину деталей, менш помітних оку (JPEG).
- **Ключ** — секретне число/правило для шифрування й розшифрування.
- **Шифр Цезаря** — навчальне правило зсувати літери на фіксовану кількість кроків.
