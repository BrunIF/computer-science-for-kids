## Bash може бути не лише інтерактивним shell

Команди, які ти вводиш одну за одною, можна записати у файл. Такий файл називають **shell script**. Bash прочитає його зверху вниз і виконає команди.

Це схоже на Python-скрипт, але мова інша й сильні сторони інші. Bash особливо зручний для запуску системних команд і з’єднання інструментів.

## Shebang пояснює, яким інтерпретатором запускати файл

Перший рядок:

```bash
#!/usr/bin/env bash
```

— це shebang. Коли файл має право `x` і запускається як `./mission.sh`, система використовує цей рядок, щоб знайти відповідний інтерпретатор.

Можна також запускати `bash mission.sh` без execute bit, бо тоді ти прямо запускаєш Bash і передаєш йому файл.

## Змінні та підстановка команд

Bash має змінні:

```bash
name="Marko"
echo "$name"
```

А конструкція `$(command)` бере текстовий результат команди:

```bash
kernel=$(uname -r)
echo "Kernel: $kernel"
```

Так ми можемо побудувати простий системний звіт.

## Linux-лабораторія: Marko System Badge

Створи `~/marko-lab/bash/mission.sh`:

```bash
#!/usr/bin/env bash

name="Marko"
kernel=$(uname -r)
os=$(grep '^PRETTY_NAME=' /etc/os-release | cut -d= -f2-)

printf '=== System Badge ===
'
printf 'Engineer: %s
' "$name"
printf 'OS: %s
' "$os"
printf 'Kernel: %s
' "$kernel"
printf 'Home: %s
' "$HOME"
```

Потім:

```bash
chmod +x mission.sh
./mission.sh
./mission.sh > report.txt
cat report.txt
```

`HOME` — змінна середовища. Не додаємо до звіту IP, токени або інші зайві приватні дані.

## Терміни однією фразою

- **Shell script** — файл із командами, який Bash читає зверху вниз.
- **Shebang (`#!/usr/bin/env bash`)** — перший рядок, який каже, яким інтерпретатором запускати файл.
- **`chmod +x`** — додає право на виконання файлу.
- **`$(command)`** — підстановка результату команди в Bash.
- **Змінна Bash** — іменований контейнер для тексту (наприклад `name="Marko"`).
- **`$HOME`** — шлях до домашнього каталогу користувача.
- **`nproc`** — показує кількість логічних CPU.
