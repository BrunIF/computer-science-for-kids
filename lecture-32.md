## Роутер з’єднує мережі

Домашній роутер — це не просто «коробка, яка робить Wi‑Fi». Одна з його головних ролей — **маршрутизувати**, тобто передавати пакети між мережами.

Усередині дому він часто також є Wi‑Fi-точкою доступу, DHCP-сервером, firewall і виконує інші функції. Один пристрій поєднує кілька ролей.

## Default gateway — двері з локальної мережі

Якщо твій ноутбук хоче доставити пакет адресі, яка не знаходиться у його локальній мережі, він зазвичай відправляє пакет **шлюзу за замовчуванням** — default gateway. Удома це часто адреса роутера.

## DHCP допомагає автоматично отримати налаштування

Коли телефон приєднується до Wi‑Fi, ти зазвичай не вводиш IP, маску, gateway і DNS вручну. Часто **DHCP** видає потрібні параметри автоматично.

Це схоже на стійку реєстрації в готелі: ти приходиш, а система каже, який «номер кімнати» тимчасово використовувати.

DHCP lease — адреса часто видається на певний час, тому вона може змінюватися.

## Linux-лабораторія: знайдемо шлюз

```bash
ip route
```

Шукай рядок, що починається приблизно так:

```text
default via 192.168.1.1 dev ...
```

Адреса після `via` — типовий кандидат на default gateway.

## Місія для Марка

Виконай місію по черзі. Якщо щось не виходить — спочатку перечитай приклад вище й спробуй знайти, на якому кроці результат відрізняється.

1. виконай `ip route`
2. знайди рядок `default`
3. намалюй схему зі своєю умовною адресою, gateway і Internet
4. поясни, навіщо DHCP потрібен новому телефону у Wi‑Fi
5. назви щонайменше три ролі, які часто виконує домашній роутер

## Терміни однією фразою

- **Роутер (router)** — пристрій, що передає пакети між мережами.
- **Default gateway (шлюз за замовчуванням)** — типовий наступний крок для трафіку поза локальною мережею.
- **DHCP** — служба, що автоматично видає адресу, маску, gateway і DNS «при вході» (наче стійка реєстрації в готелі).
- **DHCP lease** — тимчасове «зняття кімнати»: адреса видається на певний час.
- **Точка доступу (access point)** — те, що створює Wi‑Fi-хмаринку.
- **Firewall** — фільтр, який вирішує, яким пакетам можна проходити.
- **`ip route`** — команда, що показує таблицю маршрутів.
